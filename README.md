# Frontend - Juego de Trivia

## Descripción
Frontend moderno para juego de trivia en tiempo real construido con React, Socket.IO y Framer Motion.

## Características
- ✅ Interfaz moderna y responsive
- ✅ Conexión en tiempo real con Socket.IO
- ✅ Animaciones fluidas con Framer Motion
- ✅ Sistema de salas y lobby
- ✅ Interfaz de juego intuitiva
- ✅ Sistema de puntuación en tiempo real
- ✅ Diseño mobile-first

## Instalación
```bash
npm install
```

## Scripts disponibles
- `npm start` - Ejecuta la aplicación en modo desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm test` - Ejecuta las pruebas

## Estructura del proyecto
```
Front/
├── public/
│   ├── index.html
│   └── favicon.ico
├── src/
│   ├── components/        # Componentes reutilizables
│   ├── pages/             # Páginas principales
│   ├── hooks/             # Custom hooks
│   ├── services/          # Servicios y API
│   ├── utils/             # Utilidades
│   ├── styles/            # Estilos globales
│   ├── App.js             # Componente principal
│   └── index.js           # Punto de entrada
└── package.json
```

## Tecnologías utilizadas
- **React 18** - Framework principal
- **Socket.IO Client** - Comunicación en tiempo real
- **Framer Motion** - Animaciones
- **React Router** - Navegación
- **Axios** - Peticiones HTTP
- **Lucide React** - Iconos
- **React Hot Toast** - Notificaciones

## Configuración
La aplicación se conecta automáticamente al backend en `http://localhost:3001` mediante el proxy configurado en package.json.

## Desarrollo
```bash
npm start
```
La aplicación se ejecutará en `http://localhost:3000`
